# SSE 断连自动恢复与会话续传设计

状态：已确认。范围：AI 助手浏览器 Service、React 会话 Hook、Express BFF AI 路由和对应自动化测试。

## 1. 目标

服务端开始返回 AI SSE 后，如果浏览器连接因网络切换、页面代理或临时连接中断而断开，系统应在短时间内继续生成并缓存事件，客户端自动携带原请求标识和最后事件序号重新连接，服务端只重放缺失事件。恢复窗口结束后，客户端显示明确的会话过期错误，用户仍可使用现有手动重试。

本次不引入数据库、Redis、Socket.IO、跨实例会话共享或模型供应商专用续传协议。

## 2. 方案

### 2.1 服务端短时会话

Express BFF 为每个合法 AI 请求生成或接收受约束的 `X-AI-Request-Id`，以请求体哈希校验重连请求仍属于同一会话。进程内会话注册表保存：

- 请求 ID 和请求体指纹；
- 单调递增事件序号；
- 最近一段 SSE 事件，受事件数和总字节数限制；
- `active`、`completed`、`failed` 状态；
- 当前上游 AbortController；
- 最近访问时间和短时过期定时器。

响应订阅者断开时只移除浏览器响应，不立即中止已选 provider；会话在恢复窗口内继续读取上游并缓存事件。恢复请求携带 `Last-Event-ID`，服务端重放更大的事件序号后继续推送。缓存不足、指纹不匹配或会话过期时返回稳定错误码，不重新调用 provider。

30 秒保留计时从最后一个浏览器订阅者断开后开始；已连接的流不受续传 TTL 限制。会话完成或失败后同样保留 30 秒，以便客户端重放终态事件。活动连接建立前由现有 provider 请求超时保护，上限会话数触发淘汰时仍会立即中止对应上游请求。每个未完成的 SSE 帧最多 64 KiB；provider 转换层和会话事件泵都检查该上限，超出时中止上游并以安全错误结束会话。

默认恢复窗口为 30 秒，单会话最多缓存 256 个事件或 512 KiB，服务端进程最多保留 100 个恢复会话；单个未完成 SSE 帧限制为 64 KiB。配置值通过 `BFF_AI_STREAM_RESUME_TTL_MS` 等服务端环境变量读取并限制上限，缺少配置时使用安全默认值。

### 2.2 客户端自动恢复

`streamChatMessage` 为一次逻辑请求生成稳定的随机 `requestId`，解析 SSE 的 `id:` 字段并记录最后序号。遇到网络异常、读取异常或没有 `[DONE]` 的 EOF 时，最多按 200ms、400ms、800ms 的指数退避重连，重连使用相同请求体、请求 ID 和 `Last-Event-ID`；若尚未收到带 ID 的事件，则从序号 `0` 恢复。服务端重放机制保证已收到的增量不会重复调用 `onChunk`。

显式 `event: error`、HTTP 4xx/5xx、会话过期和请求指纹冲突不自动重试。超过自动恢复次数后返回现有 `failed` 结果，保留已生成文字并显示手动重试入口。

### 2.3 React 会话状态

Hook 使用本地递增序号隔离旧回调；Service 单独生成随机 SSE `requestId` 并在重连时保持不变。自动恢复期间 `isStreaming` 保持为真，界面显示“连接中断，正在恢复（第 N 次）”；恢复成功后清除该提示。最终失败仍复用既有错误和手动重试快照，不重复追加用户消息，并在手动重试前移除失败的半截回复。主动停止、关闭、清空和卸载会使本地请求失效并 abort，不触发自动恢复。

## 3. 错误与安全边界

- 请求 ID 仅允许 ASCII 字母、数字、点、下划线、冒号和短横线，最大 128 字符；服务端不得把它拼接为文件路径或上游 URL。
- 请求体指纹只在服务端内存中使用，不写入日志，不向 provider 发送。
- SSE 事件缓存只保存已经转换后的安全 Chat Completions 事件，不保存 provider 原始错误正文或凭据。
- 上游明确失败时发送安全 `event: error` 并结束会话；错误不会转换为 `[DONE]`。
- 会话超过恢复窗口、超过缓存范围或请求体不一致时返回稳定 JSON 错误，不暴露内部状态。
- 断连后的上游继续运行受 TTL、事件数、字节数和进程会话数限制；TTL 到期主动 abort，避免无人连接时持续消耗模型资源。

## 4. 测试范围

### Service

- 请求 ID 和 `Last-Event-ID` header；
- `id:` 解析与重复事件去重；
- 网络错误、读取异常、缺失 DONE 的自动恢复；
- 指数退避和最大重连次数；
- 显式 provider error、HTTP 错误、会话过期不重试；
- 自动恢复成功后 reader 释放和最终完成。

### React Hook/组件

- 自动恢复期间保持生成状态并展示提示；
- 恢复成功清除提示；
- 最终失败仍可手动重试且不新增用户消息；
- stop、close、clear、unmount 后不自动重连；
- 旧请求回调不影响新请求。

### BFF

- 首次请求建立会话并向 provider 只发起一次调用；
- 客户端断开后 provider 继续到恢复窗口；
- 重连只重放 `Last-Event-ID` 之后的事件；
- 已完成会话可重放并结束；
- 过期、指纹冲突、缓存范围不足返回稳定错误；
- 空缓存时也能识别已淘汰事件造成的续传缺口，活动订阅期间 TTL 不会结束生成；
- 超过单帧大小上限时中止 provider 并清理流；
- provider 流异常发送安全错误并清理资源；
- TTL、事件数、字节数和会话数限制生效。

## 5. 非目标

- 跨 BFF 实例共享会话；
- 进程重启后的恢复；
- provider 侧 token 续期或模型计算断点；
- AI 会话持久化、历史检索、账户级配额；
- 修改 Python Analytics、地图、灾害数据和数据库架构。
