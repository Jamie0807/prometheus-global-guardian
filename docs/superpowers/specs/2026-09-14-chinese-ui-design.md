# 全量中文界面与品牌更新设计

## 目标

将浏览器端所有面向用户的静态界面文案统一为简体中文，移除 Header 的品牌 Logo，并将平台标题固定为“全球灾害监控平台”。改动不改变后端协议、灾害类型标识、外部数据字段或分析语义。

## 范围

覆盖 Header、监控状态面板、灾害筛选与图例、地图 Popup、Analytics 页面、AI 助手、设置、报告、通知、空状态、错误提示和浏览器测试中的可见文本。需要同步更新组件和 E2E 测试断言。

保留以下非界面标识的英文：API 路径、环境变量、TypeScript/Python 类型、灾害类型 ID、外部数据源名称、AI Provider 名称、测试 fixture 字段、日志事件名和技术文档中的代码标识。灾害类型以中文展示名映射现有英文 ID，例如 `FLOOD` 显示“洪水”。

## 设计

界面文案按职责集中维护：灾害类型展示名继续由 `src/config/displayedTypes.ts` 提供；各组件的局部文案保留在所属组件或 feature；Analytics 已有中文呈现工具时优先复用。此次不引入 i18n 框架或运行时语言切换，因为产品目标是固定中文界面，额外抽象不能提升当前交付价值。

Header 移除 Logo 图片及其布局占位，不保留隐藏资产或空白容器。原品牌双行标题替换为单一中文标题“全球灾害监控平台”。导航按钮、弹窗、统计标签、筛选标签、图例、地图 Popup 和交互提示使用自然、稳定的中文词汇，避免翻译数据 ID 或外部服务名称。

## 验收标准

- Header 不渲染 Logo，且可访问标题为“全球灾害监控平台”。
- 截图标注的 Header、监控面板、筛选、刷新按钮和灾害图例均为中文。
- 其余前端静态可见英文文案也完成中文化；保留的英文必须是技术标识或外部数据内容。
- 现有交互、筛选值、API 请求、灾害类型 ID、服务边界和状态归属保持不变。
- 组件和 E2E 测试通过中文可见文字验证关键 UI；Service、BFF 和 Python 测试不因展示文案修改而变更。
- 客户端类型检查、相关组件/E2E 测试、格式检查和 `git diff --check` 通过。

## 风险与边界

地图标签、外部事件 title/description、Mapbox 地名和上游返回内容不属于本地静态文案，不能由本次改动翻译。浏览器运行时收到的未知灾害类型维持现有回退表现。若某处英文来自第三方组件默认值，仅在可通过本地 props 或配置安全覆盖时改为中文。
