# 状态面板可用性与数据提示设计

## 目标

将产品标题更新为“实时全球环境灾害监控平台与可视化平台”，修复首页状态面板的筛选和对齐问题，并移除地图左上角的运行状态横幅。

## 已确认的产品决策

- 首页和浏览器标题使用完整的新标题。
- 不在地图页面显示数据源可用性、备用数据、缓存、过期时间或最近成功时间。
- 灾害类型筛选始终显示项目支持的类型，不依赖可能失败的外部类型接口。
- 后端继续保留主源、备用源和缓存的现有治理行为；运行诊断信息仅写入既有日志和通知体系，不覆盖地图。

## 方案

`DISPLAYED_TYPES` 是当前图例和筛选的产品展示清单。状态面板直接从它生成选项，保留稳定的 `type_id` 作为 select 值，不再请求 `/api/hazards/types`。因此筛选器无需加载态，也不会因 DisasterAWARE 认证、网络或代理失败而变为空列表。

`MapView` 继续接收 `sourceMeta`，以避免改变数据加载边界；仅删除将元数据渲染为可见状态横幅和“暂无可用灾害数据”的分支。这样刷新流程、地图图层和 BFF 的回退策略均不变。

状态面板的统计卡将标签和值以明确的 `gap` 排列；刷新按钮使用共享按钮样式中的 `justify-content: center`，确保按钮宽度变为 100% 时内容保持水平居中。标题保留单行优先、窄屏时按现有响应式规则缩放。

## 验收标准

1. `Header` 和 `index.html` 都显示“实时全球环境灾害监控平台与可视化平台”。
2. 状态面板立即提供“全部灾害”和 `DISPLAYED_TYPES` 的 14 个中文选项，选择“洪水”仍传递 `FLOOD`。
3. 地图在任意 `sourceMeta` 状态下均不渲染状态横幅或“暂无可用灾害数据”提示。
4. 刷新按钮在宽度为 100% 时文字和图标水平居中；统计标签和值之间存在稳定间距。
5. 类型检查、组件测试、E2E、构建和差异检查通过。
