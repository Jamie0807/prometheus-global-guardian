# Orbital 全球监控地图视觉升级设计

**日期：** 2026-09-20

**状态：** 已实施并完成本地验证（2026-09-20）

## 目标

将灾害监控首页从“深色地图加散点”提升为有空间感、层级清晰的全球态势大屏。主方向采用用户选择的 **02 / Orbital「深空态势」**，保留 Mapbox GL 和现有业务数据，以平面 Mercator 作为 2D 总览、Globe 作为 3D 地球，并改进地图周边界面与标注。

## 已确认的产品决策

- 视觉方向采用深蓝深空、克制的大气光晕与更有秩序的事件层级；不追求持续旋转、强动画或霓虹堆叠。
- 首页默认使用 2D 地图模式，用户可主动切换到轻量 3D，也可随时切回 2D。
- 全屏地球仍为主视觉；改版范围包括地图首页的导航与状态/图例覆盖层，不扩展到分析页或其他模块。
- 保留现有 Mapbox GL、灾害数据源、筛选、热力图、聚合、Popup 和 API 契约；不新增灾害数据或服务接口。
- 本轮仅做前端视觉与地图交互改造，不引入地图引擎替换或新的 UI 依赖。

## 当前实现边界

- `useMapboxInstance` 以 `projection: "mercator"` 创建地图，避免默认 2D 首屏出现球形地球；模式 Hook 在 3D 时运行时切换为 Globe，并配置 Terrain 与相机 pitch。
- `useDeck3DTiles` 在 3D Globe 模式统一使用 Mapbox 原生建筑拉伸图层，并由现有 LOD 逻辑控制。Mapbox 的 deck.gl 集成不支持 Globe 等非 Mercator 投影；若配置了外部 3D Tiles，则在建筑缩放级别以一次性非阻塞通知说明已使用原生建筑回退，不挂载错位的 deck.gl overlay。
- `useHazardLodLayers` 已有灾害聚合、单点和高缩放建筑显隐逻辑；本轮优化其视觉呈现，不重复实现聚合机制。
- `Header`、`StatusPanel` 和 `LegendPanel` 已构成地图页面的主要覆盖层，应在原有交互上统一视觉，而不是新增一套重复的监控侧栏。

## 设计方案

### 视觉层级

- 地球和灾害图层占据视觉中心。底图继续使用深色 Mapbox 风格，控制大面积光效；现有 fog 保留并调整到与深空蓝、浅青色地平光一致。
- 顶部导航收敛为清晰的品牌/页面标题与紧凑操作区，避免长标题和按钮组压过地图。
- 状态面板与图例保留现有功能，改为尺寸更克制、半透明、对比度充足的浮层；移动窄屏时可折叠，不遮住主要地图区域。
- 使用现有灾害类型颜色语义区分事件。聚合圆、单点描边和文字优先保证识别，减少粗重黑描边、过大的光晕和不必要的标签；全局缩放下减少非关键地名的视觉权重。
- 地图事件详情继续通过现有 Popup 呈现，不添加新的常驻事件信息流或虚构指标。

### 2D / 3D 模式行为

- 新增前端地图视图模式状态，初始为 `2d`，页面重新加载后仍回到 `2d`；本轮不持久化用户偏好。
- 在地图首页的显眼但不抢眼位置提供有标签的 2D/3D 切换控件。控件支持键盘操作，并通过 `aria-pressed` 暴露当前模式。
- `2d` 模式使用 Mercator 平面投影、pitch 0、不启用 Terrain、不显示建筑挤出或外部 3D Tiles；现有事件数据、筛选与热力图不变。
- `3d` 模式保留 Globe 投影与 fog，以约 42° 的 pitch 和 1.8 倍地形夸张增强可感知的空间起伏。使用 Mapbox Raster DEM 与 `setTerrain`；Mapbox 原生建筑拉伸只在 3D 模式启用，并继续遵循现有高缩放 LOD 规则。由于 Mapbox 的 deck.gl 集成不支持非 Mercator 的 Globe 投影，已配置的外部 3D Tiles 不会在 Globe 模式挂载，而是在建筑可见级别使用原生建筑回退并提示一次。切换控件使用明确的“3D 地形”标签。
- 切换采用短暂的地图相机过渡；尊重系统减少动态效果偏好，避免影响灾害位置与筛选状态。
- Mapbox GL JS 文档列明 Terrain 可用于 Globe 与 Mercator 投影，并通过 `raster-dem` source 和 `setTerrain` 启用：[Projections](https://docs.mapbox.com/mapbox-gl-js/guides/projections/)、[Add 3D terrain](https://docs.mapbox.com/mapbox-gl-js/example/add-terrain/)。

### 失败处理与性能边界

- DEM 加载失败时，保留可交互的 Globe 和灾害数据，关闭地形并显示一次非阻塞提示；用户可继续使用 2D 或 pitch-only 的 3D 视图。
- Globe 模式不挂载 Mapbox/deck.gl 不兼容的外部 3D Tiles overlay；配置了外部瓦片时按现有建筑拉伸能力回退，并在高缩放级别提示一次。无法添加建筑时隐藏立体建筑层，但保留全部灾害图层。
- 2D 模式不创建或启用额外的地形/3D Tiles 渲染负担；不增加常驻动画或第二个 WebGL canvas。
- 图层切换必须处理地图样式重载与组件卸载，避免重复 source/layer、重复事件监听器或遗留 WebGL 资源。

## 范围外

- 不替换 `dark-v11` 或地图供应商，不迁移到 Cesium，也不引入新的 3D 渲染引擎。
- 不调整灾害数据源、风险评分、筛选语义、分析模型、后端接口或数据契约。
- 不重做 Analytics 页面，不新增常驻事件列表、统计 KPI、用户偏好存储或地图自动旋转。
- 不移除现有 3D Tiles 配置能力；只让它服从首页的 2D/3D 模式。

## 验收标准

1. 初次打开地图首页为 2D Mercator 平面地图；切换 3D 后改为 Globe 地球，灾害数据、筛选和现有图例正常。
2. 2D/3D 控件可以通过鼠标与键盘切换；模式指示同步更新，切换前后的灾害集合、筛选值、热力图状态和 Popup 语义保持不变。
3. 3D 模式启用约 42° pitch 与 1.8 倍 Terrain；切换控件明确显示“3D 地形”。城市缩放时建筑按现有 LOD 规则出现。回到 2D 后 pitch、terrain 与 3D 建筑/瓦片均关闭。
4. DEM 加载失败时，地图与灾害交互仍可用；已配置外部 3D Tiles 时 Globe 模式改用原生建筑层，不挂载不兼容 overlay，并在高缩放级别提示一次；提示不遮挡地图。
5. 顶部导航、状态面板、图例使用一致的层级、间距、对比度和半透明表面；国家/灾害标签不再以粗重黑边和低对比度压过底图。
6. 在桌面与窄屏视口中，2D/3D 控件、状态面板和图例不互相覆盖，主要地图区域仍可操作。
7. 现有灾害聚合和图层 LOD 保持工作；项目类型检查、组件测试、相关 E2E 与生产构建通过。

## 验证方案

- 使用 Vitest 覆盖模式状态到 camera pitch、terrain 与 3D 图层显隐策略的映射，以及 DEM 失败时的回退行为。
- 使用组件测试验证默认 2D 状态、切换控件的可访问名称/按压状态，以及切换不重置现有筛选与热力图状态。
- 使用 Playwright 验证首页默认模式、切入/切出 3D、地形或瓦片失败时仍可交互，并在桌面与窄屏检查覆盖层布局。
- 运行项目配置的 lint、格式、相关测试、客户端/服务端/契约类型检查、构建及 `git diff --check`；不因纯视觉改动扩大到无关测试或依赖升级。
