# 分析面板与通知按钮视觉统一设计

## 目标

让数据分析面板和首页通知按钮使用与首页地图、状态面板和图例一致的深蓝玻璃视觉语言，消除分析页大面积黑灰底与绿色强调色造成的割裂感。

## 已确认的设计方向

- 分析页的背景、卡片、边框、标题、按钮、标签页、图表容器和交互状态统一使用深海军蓝面板与青蓝强调色。
- 分析页沿用首页现有配色：深色半透明底、浅蓝细描边、青蓝焦点和选中态、浅色正文。阴影保持克制，不再以绿色作为装饰性强调色。
- 分析页标题及各级标题、标签页、刷新按钮使用与首页“数据分析”按钮相同的线性 SVG 图标风格，替换 emoji 图标。
- 主色统一为首页深海军蓝、青蓝和蓝色系；图表分类只使用不同明度的蓝青色，卡片边框回归低对比蓝灰色，不使用高饱和度彩虹色。
- 正常状态使用青蓝，警告和高风险使用琥珀色，失败/严重故障使用珊瑚色；状态色只出现在小型标签、数字或提示文字中，不用于大面积卡片边框或填充。
- 通知中心面板及图表详情弹窗继续使用首页的海军蓝玻璃底、浅蓝细描边和青蓝强调色；成功/信息图标不再使用绿色/亮蓝实心圆，严重程度只在小型标签中使用琥珀/珊瑚色。
- 分析页所有剩余 emoji 标识（包括预测灾害类别、建议、时间和说明图标）替换成同一描边 SVG 图标风格；灾害类型标签仍保留清晰的类别含义。
- 首页通知按钮使用与其他标题栏按钮同一线性图标风格；未读数量徽标继续使用红色。
- 页面布局、数据、交互和通知行为不变。

## 方案

以 `src/index.css` 中 `.header-action`、`.status-panel` 和 `.legend-panel` 的配色与边框作为现有设计基准。为分析页建立局部样式令牌，覆盖全屏底板、摘要卡、分析控制区、完成提示、标签页和各结果标签的外层容器。将分析组件中分散的装饰性黑灰、彩虹分类色和强烈状态边框替换为局部令牌或受控状态色；通用 `DataVisualization` 组件若需调整，只调整分析页实际使用的指标、进度条和图表视觉，不改变其数据计算。

分析区图标使用可复用的线性 SVG 组件，`chart` 图标复用首页“数据分析”按钮的路径，其他图标沿用相同描边、尺寸和 `currentColor` 规则；保留现有文案与可访问名称。图表分类色表只在分析页消费的 `ChartsPanel` 中调整，不影响地图首页其他 UI。

通知按钮继续使用标题栏现有 `.header-action` 布局和交互样式，将 emoji 铃铛替换为与其他导航动作一致的描边 SVG。徽标位置与尺寸保持清晰可读，键盘焦点继续使用现有青色焦点描边。

视觉样式限定在分析页及通知按钮，不修改首页地图、其他弹窗、数据计算或通知中心的状态管理。实现遵循现有 React + TypeScript 组件边界，尽量移除分析页的逐元素内联装饰样式，使用局部 CSS 类和共享分析主题常量，避免全局样式泄漏。

## 验收标准

1. 分析页从总览、图表、预测、风险到数据质量标签页均采用深蓝玻璃底、浅蓝边框和青蓝交互态，不再以绿色作为大面积装饰强调色。
2. 摘要卡、分布条、控制区、完成提示、标签页和图表/质量结果容器在桌面和窄屏下保持清晰层级与可读间距。
3. 服务状态、风险等级和告警以青蓝、琥珀、珊瑚色及图标/文字区分；琥珀和珊瑚仅用于状态标签、数值或提示，不作为大面积装饰边框。
4. 分析标题、标签页和主要区块图标使用与首页相同的描边 SVG 风格；图表类别仅使用蓝青色阶，卡片边框保持低对比蓝灰色。
5. 首页通知按钮的铃铛图标与其他标题栏线性 SVG 图标一致；未读计数、按钮开合和通知数据行为不变。
6. 所有新增按钮样式具有可见 hover 与键盘焦点状态；窄屏下通知徽标不遮挡按钮文字。
7. 分析和通知相关组件测试、格式检查、类型检查、lint、构建及 `git diff --check` 通过。
