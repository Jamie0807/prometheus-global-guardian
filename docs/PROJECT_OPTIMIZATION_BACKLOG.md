# 项目待优化清单

最近核对日期：2026-09-27。本文档只记录相对当前代码仍未完成的优化、遗留风险和后续判断；已实现的稳定架构看 `docs/PROJECT_SPEC.md`，测试证据看 `docs/TESTING_BASELINE.md`，数据库操作看 `docs/OPERATIONS_PERSISTENCE.md`。

## 1. 当前项目状态

项目已经具备 React + Vite 前端、Express BFF、FastAPI Analytics、多源灾害聚合、Mapbox 地图、分析工作台和 AI 助手。当前目标仍是本地或私有自托管，不代表已经具备公网生产能力。

当前已落地的主干能力：

- Web、BFF、Analytics 三个运行单元和 `packages/` 共享契约边界；
- DisasterAware、USGS、NASA EONET、GDACS 的多源灾害获取、缓存、降级和来源健康快照；
- `Hazard` canonical 事件字段、图层注册表和 TypeScript/Python 共享契约；
- 用户注册、登录、全站会话门禁、账号隔离的 AI 对话/消息/同会话摘要持久化；
- AI SSE 取消、失败终态、手动重试、单实例有限断点续传和请求隔离；
- Workflow 的实时上下文判别：`hazard_context_available`、`hazard_context: null` 缺失语义、`byType` 全量统计和 `recent` 代表样本边界；
- 外部 ai-workflow 的 RAG 知识库集成边界：文档由外部 Workflow 管理，不写入本项目 PostgreSQL；
- 本地/私有单机 PostgreSQL 检查、备份、恢复演练、7 个自然日清理和手动 migration 流程；
- lint、格式、类型检查、架构/Docker 校验、Node、组件、E2E 和 Python 测试入口。

## 4. 遗留风险

### AI 与会话

- Provider 降级只发生在响应开始前，没有健康探测、熔断、持久化失败计数或用户/模型配额。
- SSE 续传缓存是单实例短时有界内存，进程重启、多实例共享、跨标签并发限制和跨实例限流仍未实现。
- RAG 文档、索引和召回质量依赖外部 ai-workflow；本项目的 BFF 测试不能证明外部知识库内容完整或模型一定引用正确章节。

### 灾害数据与 Analytics

- PostgreSQL 当前保存账号和 AI 数据，不保存灾害历史；复杂几何、历史快照、回放和审计仍需独立设计。
- 数据源健康指标只保留当前 BFF 进程固定五分钟窗口，没有跨实例汇总、历史趋势、持久化指标或告警。
- 多来源 `severity` 与 `magnitude` 不天然可比较；预测置信度、风险阈值、估算震级和质量规则仍需真实业务样本校准。
- Analytics `data` 内部字段的完整跨语言模型尚未统一，不能仅根据顶层响应信封推断内部 4D 数据契约已经完成。

### 运行与交付

- 项目没有部署工作流，不自动发布镜像或执行数据库 migration。
- BFF 限流是单进程内存和直连 IP 计数；公网部署需要网关或共享存储以及可信代理设计。
- 当前 CI 不做视觉回归、依赖/镜像/许可证/secret 扫描，也不验证真实第三方服务。

## 5. 质量入口

日常变更按边界执行定向测试；完整 Node 与 Python 入口如下：

```bash
pnpm run test:baseline
pnpm run test:python
```

最新 Workflow 上下文定向回归为 23/23，详细命令和历史环境限制见 `docs/TESTING_BASELINE.md`。本清单不重复维护测试数量，避免与测试证据产生双份事实。

## 6. 后续执行原则

- 新增接口先定义输入、输出、失败语义和测试，再接入页面或路由。
- 外部 JSON、浏览器事件和网络响应保持 `unknown` 边界，解析成功后才进入领域类型。
- 共享输入变化同步修改 JSON 样本和 TypeScript/Python 双端测试。
- 服务端凭据只由 BFF 或 Python 运行时读取，不进入 `VITE_*` 或前端构建产物。
- 新增 BFF 上游能力继续明确路径、方法、query、body、header、超时、响应大小和脱敏错误边界。
- 不为未来假设提前引入数据库历史层、消息队列、GPU 集群、完整应急协同或公网基础设施；先确认需求和验收标准。
